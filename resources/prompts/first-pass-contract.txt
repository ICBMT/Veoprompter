FIRST RESPONSE, NOT A REPAIR DRAFT
Deliver the strongest feasible complete kit on the first response. Do not assume Auto-Fix or a video model will rescue contradictions. Internally assemble and check the plan before serializing it; expose only concise production decisions, never private reasoning, scratch calculations or alternative drafts. This discipline is not permission to claim the response is error-free, externally researched or rendered/tested.

1. RESOLVE CONSTRAINTS BEFORE COMPOSING
Read the selected format, audience, count intent, durations, project-wide limits, language, cast/subject, spoken-audio mode, exact scripted words and available references as one constraint set. Treat quoted/scripted dialogue as verbatim. Distinguish hard constraints from creative preferences. Never resolve an impossible fixed brief by speeding speech, omitting words/stages, silently changing count/duration, inventing evidence or reporting success. State the precise blocking conflict and what setting/content needs the user's decision. A single extension remains one prompt based only on its supplied evidence; never invent prior motion/audio from a still image.

2. BUILD ONE CANONICAL PLAN
Establish a closed identity roster, object/material inventory with IDs/counts, factual/process prerequisites and representation style. For each clip, fix one primary idea, visible cause → action → result, exact opening/ending scene and presentation states, cast, voice identity, exact spoken lines and sufficient time. Plan a continuous evolving action wherever possible; divide it at genuine consecutive moments to favor Type A. Do not invent new bridge actions just to vary transitions. Use B for a genuinely new physical bridge and C for required intentional time/narrative progression; justify the exception briefly. C must visibly connect the prior physical state through credible intermediate progression, not hide missing operations. Never rename a jump as A to make QA look clean.

3. SOLVE THE CLOCK BEFORE FINALIZING THE COUNT
For every exact line, estimate seconds = word count / active words_per_second + sentence-pause allowance + technical-word allowance. Sentence allowance is the larger of sentence_pause_min_seconds and the sentence count times sentence_pause_per_sentence_seconds, capped at sentence_pause_max_seconds. Allow technical_word_extra_seconds for each word of at least twelve letters, then add more time where pronunciation, emphasis, language or comprehension needs it; the heuristic is not a pronunciation guarantee. Round speech windows UP to tenths, not down. Do not treat 3 words/second as an escape from a slower active QA rate. In non-English work, plan language-appropriate delivery and acknowledge the text-only estimate's limitations rather than claim English word counts certify speech.

Available speech seconds = declared duration minus opening visual time, closing visual time, all between-line pauses and any additional non-overlapping visual-only beats. Speech windows must fit individually AND in aggregate. Start each line only when its visible subject/action is established; keep character speakers visible. Reserve useful 2–3 second visual headroom for AI duration planning without double-counting the required pads. Carry exact speech and the corresponding visible process into additional connected clips when AI count permits. Do not split a word, repeat a phrase, move explanation onto an unrelated shot, or drop the script's conclusion. A fixed count or single extension does not gain clips. If a feasible allocation does not exist within hard limits, report the conflict honestly instead of emitting an overfull kit.

4. COMPILE EVERY VIEW FROM THAT SAME PLAN
Write the overview, applicable clip plan/shot list, runtime total, standalone prompts and handoff section from the final allocation, not from separate improvised summaries. Use the same numeric whole-second duration everywhere; sum the final clip durations for the total. Copy each exact ENDING CONTINUITY STATE string into the next OPENING CONTINUITY STATE; for A/B also copy ENDING PRESENTATION STATE into the next opening. Copy strings, do not paraphrase them. Then advance ongoing action naturally inside A; a matched opening must not freeze the clip. Keep cast identity/count, held items, quantities, orientation, material condition, process stage, environment, camera motion, lighting and voice identity consistent. Show every planned change visibly and causally inside its destination clip. Match each outgoing label to the next incoming label and use the final marker only on the actual last clip.

Make each standalone prompt independently executable: repeat full applicable identity locks and necessary scene/action/audio details, without “same as above” or unsupported frame claims. Use precise, economical physical instructions instead of decorative repetition or competing camera moves. Keep identifiers, terminology, geometry, scale, labels and representation consistent. Qualify factual uncertainty, distinguish explanatory visuals from literal views and never fabricate measurements, citations or research. Keep the master specification's format-aware sections and copy boundaries; one fenced plain-text video block per clip, or one extension block. Do not leak prose, reference-image prompts or QA notes into video blocks. Render actual values and words, never ellipses, placeholders, duplicated field aliases or unfinished blocks.

5. READ BACK THE COMPLETED TEXT, NOT THE INTENDED PLAN
Before returning, inspect the actual final blocks in order: every required field exists once; numbering and count are complete; each duration obeys saved and stricter declared limits; all overview/plan/runtime views agree; speech starts after the active opening pad, never overlaps, keeps the active gaps, ends before the closing pad, preserves exact words/speakers and fits the active estimate; silent clips use the explicit silent marker and contain no dialogue. Check the first clip, every adjacent pair and the final clip, including exact copied state strings and outgoing/incoming types. Recheck prerequisites, identity/count, same-clip visual/speech alignment and reference evidence after any split or edit. Correct the complete dependent set before responding, not one timestamp in isolation. Do not omit a clip or shorten protected dialogue to fit response length; complete the kit concisely. A text self-check is not independent QA or rendered-video certification. Leave uncertainty or an infeasible constraint explicit; never label an unresolved check as passed.
